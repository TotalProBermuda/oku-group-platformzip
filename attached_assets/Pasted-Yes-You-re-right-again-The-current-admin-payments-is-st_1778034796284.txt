ENCRYPTION REQUIREMENT
Add one required environment variable:
- APP_ENCRYPTION_KEY

This key is used only to encrypt/decrypt stored gateway credentials.
If APP_ENCRYPTION_KEY is missing:
- credential editing is disabled
- page shows: “Credential editing unavailable. APP_ENCRYPTION_KEY is missing.”
- existing env-based credentials can still be detected.

Schema:
Add model PaymentGatewayCredential:

model PaymentGatewayCredential {
  id String @id @default(cuid())

  provider String @default("AUTHORIZE_NET")
  label String @default("Authorize.net Credit Card")
  isActive Boolean @default(true)

  environment String @default("sandbox") // sandbox | production
  connectionType String @default("gateway_only") // gateway_only | all_in_one

  apiLoginIdEncrypted String?
  transactionKeyEncrypted String?
  signatureKeyEncrypted String?

  apiLoginIdLast4 String?
  transactionKeyLast4 String?
  signatureKeyLast4 String?

  merchantProviderName String? // e.g. Banesco, FAC, processor name
  merchantIdLast4 String?
  terminalIdLast4 String?

  checkoutTitle String @default("Credit Card")
  checkoutDescription String @default("Pay securely using your credit card.")
  enableGateway Boolean @default(false)
  displayCsc Boolean @default(true)
  transactionType String @default("charge") // charge | authorize_only
  detailedDeclines Boolean @default(true)
  debugMode String @default("off") // off | errors | verbose
  acceptedCardLogos Json?

  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt
  updatedById String?
}

Encryption helper:
Create src/server/security/encryption.ts

Use Node crypto AES-256-GCM.
APP_ENCRYPTION_KEY must be 32 bytes after decoding.
Support base64 key.
Export:
- encryptSecret(value: string): string
- decryptSecret(payload: string): string
- maskSecret(value: string): { last4: string }

API routes:
1. GET /api/v1/admin/payments/gateways
- SUPERADMIN only.
- Returns provider settings and masked credential status only.
- Never returns decrypted secrets.

2. PATCH /api/v1/admin/payments/gateways/authorize-net
- SUPERADMIN only.
- Accepts:
  - enableGateway
  - environment
  - connectionType
  - apiLoginId
  - transactionKey
  - signatureKey
  - merchantProviderName
  - merchantId
  - terminalId
  - checkoutTitle
  - checkoutDescription
  - displayCsc
  - transactionType
  - detailedDeclines
  - debugMode
  - acceptedCardLogos
- Encrypts credential fields before saving.
- Stores only last4 for display.
- If a credential field is blank, keep existing value.
- If clearCredential=true for a field, remove it.
- Writes AuditLog with before/after for non-secret fields only.
- AuditLog may say “apiLoginId changed: true” but must not store values.

3. POST /api/v1/admin/payments/gateways/authorize-net/test
- SUPERADMIN only.
- Decrypts saved credentials if present.
- Falls back to env vars if no saved credential exists.
- Calls Authorize.net authenticateTestRequest.
- Writes sanitized AuditLog result.
- Returns safe status.

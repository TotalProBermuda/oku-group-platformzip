[P1] Deduplication key can collide across systems.
The unique index is only (sourceRecordId, idempotencyKey) at lines 69-70. If two connectors use the same external record ID and idempotency key format, they collide. Safer unique key: (sourceSystem, sourceConnector, sourceRecordId, idempotencyKey) plus the partial internal-event index for sourceRecordId IS NULL.
[P1] “Canonical proof trail” is still best-effort only.
Reservation and host-operation events are emitted after the primary write and swallowed on failure. That avoids blocking bookings, but it means the proof trail can silently miss exactly the events investors/admins need. See lines 239-260 and 319-338. Better pattern: write an outbox row inside the same transaction, then process with retry.
